## הבדיקות מול Gemini

הופעל live_evaluation.py ונעצר עם קוד יציאה 2: חסר GOOGLE_API_KEY בקובץ .env.
לא נוצרו תשובות אמיתיות ולא נמדדו איכות סמנטית, נכונות תשובות, הימנעות מהשלמת מידע חסר, זמן תגובה או עלות API. הבדיקות המקומיות אינן מחליפות את חמש השאלות והתשובות הנדרשות להגשה.

הסקריפט כולל שבע שאלות, כולל שאלה ללא מידע ושאלת המשך. הוא בונה אינדקס זמני ומייצר live-results.json עם התשובות בפועל והמקורות, וכן ציפיות לבדיקה ידנית. יש להגדיר מפתח בסביבה המקומית; אין צורך לשלוח אותו בצ׳אט. הרצה מול Gemini כרוכה בשימוש ב-API.

## שחזור

מתיקיית הפרויקט, לאחר יצירה והפעלה של סביבה וירטואלית:

```bash
pip install -r requirements.txt pytest
python -m pytest tests/test_system.py -v
```

שלוש הבדיקות אמורות להיכשל על הקוד הנוכחי, עד שיושלם תיקון ההתנהגות הנבדקת.

לאחר הגדרת GOOGLE_API_KEY בקובץ .env בשורש הפרויקט:

```bash
python tests/live_evaluation.py
```

גרסאות החבילות שהותקנו מתועדות ב-tested-environment.txt. פלט הבדיקות המקורי ב-test-output.txt וב-results.xml.
